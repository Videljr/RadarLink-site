# RadarLink — site institucional

Landing page pública do **RadarLink**, uma plataforma em desenvolvimento para comparação de produtos, preços e ofertas de diferentes lojas online.

## Conteúdo

- Página inicial responsiva
- Explicação da proposta da plataforma
- Divulgação transparente sobre links de afiliado
- Página de privacidade
- Publicação automática no GitHub Pages

## Desenvolvimento local

O site é estático e não exige instalação de dependências. Abra `index.html` no navegador ou use um servidor HTTP local.

## Publicação

Os arquivos são publicados automaticamente no GitHub Pages a cada atualização da branch `main`, através do workflow em `.github/workflows/pages.yml`.

Endereço esperado: **https://videljr.github.io/RadarLink-site/**
